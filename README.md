# Focus Quest

Личное приложение для задач: шаги, настроение, таймер фокуса, статистика и награды.
Работает в браузере на компьютере и устанавливается на телефон как обычное приложение.

## Как пользоваться

- **Утром (5 минут).** Разберите «Входящие», выберите 1 главную задачу и 2–3 второстепенных и распределите шаги на «Неделе».
- **Днём.** Откройте «Сейчас», укажите своё состояние, возьмите задачу (или нажмите «Случайная задача») и запустите фокус.
- **Не можете начать?** Запустите фокус на 5 минут («просто начать») или разбейте шаг ещё мельче.
- **Вечером (3 минуты).** Отметьте сделанное, перенесите остальное без самокритики и загляните в «Статистику».
- **Раз в неделю (20 минут).** Посмотрите, какие задачи застряли (они подсвечены на «Статистике»), и разбейте их на шаги поменьше или удалите.

Очки: шаг приносит 10/15/20 очков в зависимости от сложности и ещё +5/+15, если задача ждала 7/30+ дней.
Завершённая задача даёт +50, каждые 5 минут фокуса +1, достижение +25. Очки тратятся в «Магазине наград»
на награды, которые вы придумываете сами. Серия дней не обнуляется из-за одного пропуска в неделю (заморозка).

| Репозиторий | Видимость | Что в нём |
|---|---|---|
| `scheduleAndDiscipline-vibe-` (код) | публичный* | код приложения; из него собирается сайт на GitHub Pages |
| отдельный репозиторий для данных | **приватный** | файл `focus-quest-data.json` с задачами, привычками и очками |

Токен GitHub и ключ Claude хранятся только в браузере и никуда не синхронизируются.

\* На бесплатном тарифе GitHub Pages работает только из публичных репозиториев.

## Простые дела и привычки

Раздел «Привычки» — универсальный пул дел в 9 категориях: планирование, спокойствие, тело, учёба и работа, дом,
забота о себе, деньги, близкие, хобби. При первом запуске пользователь выбирает интересные категории
(потом — кнопка «Настроить пул»), а неподходящие дела можно скрыть по одному.

- **Простые** (1–10 минут, +5 очков) — для дней, когда нет настроения ни на что.
  Кнопка «Нет настроения ни на что» на экране «Сейчас» показывает три таких дела.
- **Посерьёзнее** (10–45 минут, +15, а от 30 минут +20): зарядка, глубокая работа, повторение материала,
  порядок в комнате, подписки и счета, недельный обзор, хобби…

Закрепление: булавка у любого дела → как часто выполнять: по дням недели, раз в N дней или N раз в неделю.
Закреплённые привычки появляются на экране «Сейчас» в списке «Привычки на сегодня», когда их пора делать;
за выполнение всех привычек дня — бонус +10. У каждой привычки своя серия.

У каждого дела есть «Зачем», «Как закрепить» и якорь («после того как…»). Можно добавлять свои дела любого уровня.
Внизу раздела — советы, как вырабатывать привычки. Любое выполненное дело сохраняет общую серию дней.

## Задачи

- **Срок:** сегодня, 2–3 дня, неделя, до конца месяца или своя дата. Статус пересчитывается каждый день;
  за 3 дня до срока задача становится срочной и поднимается в подборке.
- **Объединение:** «Задачи → Объединить» — несколько маленьких задач становятся шагами одной большой.
- **Вернуть в работу:** случайно завершённую задачу можно вернуть (очки за завершение снимутся) —
  с плашки «Задача завершена», из списка задач или из редактора.

## Claude в приложении

Что умеет:
- **«Спросить Claude»** на экране «Сейчас»: опишите самочувствие своими словами, и Claude предложит 1–3 задачи, объяснит выбор и подскажет самое маленькое первое действие.
- **«Разбить на шаги»** в редакторе задачи: Claude предложит 3–7 конкретных шагов по 5–45 минут.
- **«Заполнить оценки с Claude»**: настроения, сложность, креативность, важность и срок.
- **«Итоги недели от Claude»** на экране «Статистика».

Подключение:
1. Зарегистрируйтесь на [console.anthropic.com](https://console.anthropic.com) и пополните баланс. Это отдельная оплата по факту использования, подписка claude.ai здесь не действует.
2. **Settings → Limits**: поставьте месячный лимит расходов, например $5.
3. **API Keys → Create Key**, скопируйте ключ (`sk-ant-…`).
4. В приложении: **Настройки → Claude**, вставьте ключ, выберите модель и нажмите «Проверить ключ».

Названия задач, шагов и заметки отправляются в Anthropic для обработки.
Модель по умолчанию — Opus 5.5 (~2–4 цента за запрос); Sonnet 5.5 вдвое дешевле, Haiku 5.5 почти бесплатна.

## Как устроена синхронизация

- Приложение работает без интернета: всё сохраняется в браузере.
- При открытии, через 4 секунды после изменений и по кнопке данные сливаются с файлом в GitHub.
- Слияние идёт по каждой записи: побеждает более свежая версия. Поэтому правки с двух устройств не затирают друг друга целиком.
- Удаление тоже синхронизируется: удалённая запись хранится с пометкой «удалено».
- Резервная копия: «Настройки → Скачать копию». К тому же GitHub хранит историю всех версий файла.

## Ограничения

- На телефоне браузер усыпляет свёрнутые приложения, поэтому уведомление о конце таймера может прийти с опозданием,
  пока вы не откроете приложение. Время при этом считается правильно.
- Вибрация в браузере на iPhone не поддерживается.

## Структура кода

- `src/types.ts` — модель данных
- `src/store.ts` — состояние и все действия (шаги, очки, таймер, награды)
- `src/lib/` — логика: прогресс, очки и серии (`game.ts`), достижения, подбор задач, синхронизация, звук
- `src/pages/` — экраны, `src/components/` — общие компоненты
