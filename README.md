# Focus Quest

Личное приложение для задач: шаги, настроение, таймер фокуса, статистика и награды.
Работает в браузере на компьютере и устанавливается на телефон как обычное приложение.

## Как пользоваться

- **Утром (5 минут).** Разберите «Входящие», выберите 1 главную задачу и 2–3 второстепенных и распределите шаги на «Неделе».
- **Днём.** Откройте «Сейчас», укажите своё состояние, возьмите задачу (или нажмите «Случайная задача») и запустите фокус.
- **Не можете начать?** Запустите фокус на 5 минут («просто начать») или разбейте шаг ещё мельче.
- **Вечером (3 минуты).** Отметьте сделанное, перенесите остальное без самокритики и загляните в «Статистику».
- **Раз в неделю (20 минут).** Посмотрите, какие задачи застряли (они подсвечены на «Статистике»), и разбейте их на шаги поменьше или удалите.

Очки: шаг приносит 10/15/20 очков в зависимости от сложности и ещё +5/+15, если задача ждала 7/30+ дней.
Завершённая задача даёт +50, каждые 5 минут фокуса +1, достижение +25. Очки тратятся в «Магазине наград»
на награды, которые вы придумываете сами. Серия дней не обнуляется из-за одного пропуска в неделю (заморозка).

## Запуск на компьютере

```bash
npm install
npm run dev
```

Откройте http://localhost:5173.

## Публикация и синхронизация через GitHub

Понадобятся два репозитория:

| Репозиторий | Видимость | Что в нём |
|---|---|---|
| `focus-quest` (код) | публичный* | этот проект; отсюда GitHub Pages раздаёт приложение |
| `my-tasks-data` (данные) | **приватный** | файл `focus-quest-data.json` с вашими задачами |

\* На бесплатном тарифе GitHub Pages работает только из публичных репозиториев. В коде нет ничего личного: все ваши данные хранятся в приватном репозитории.

### 1. Опубликовать приложение

1. Создайте на github.com репозиторий `focus-quest` (публичный, без README).
2. В папке проекта выполните (подставьте свой логин):
   ```bash
   git init
   git add .
   git commit -m "Focus Quest"
   git branch -M main
   git remote add origin https://github.com/ВАШ-ЛОГИН/focus-quest.git
   git push -u origin main
   ```
3. В репозитории откройте **Settings → Pages** и в поле **Source** выберите **GitHub Actions**.
4. Через 1–2 минуты приложение будет доступно по адресу `https://ВАШ-ЛОГИН.github.io/focus-quest/`.
   Дальше каждый `git push` будет обновлять его автоматически.

### 2. Создать репозиторий для данных

Создайте **приватный** репозиторий `my-tasks-data`. Его можно оставить пустым, приложение само создаст в нём файл.

### 3. Выпустить токен

1. Откройте github.com → аватар → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. **Repository access:** *Only select repositories* → выберите только `my-tasks-data`.
3. **Permissions → Repository permissions → Contents:** *Read and write*.
4. Срок действия выберите сами, например 1 год. Скопируйте токен (он начинается с `github_pat_`).

Токен даёт доступ только к одному репозиторию с данными и не может трогать остальные.

### 4. Подключить устройства

На каждом устройстве откройте приложение → **Настройки → Синхронизация через GitHub** и укажите:
ваш логин, `my-tasks-data`, файл `focus-quest-data.json`, токен. Затем нажмите «Синхронизировать сейчас».

Токен хранится только в браузере этого устройства. Не вводите его на чужих компьютерах.

### Установка на телефон

- **Android (Chrome):** откройте адрес приложения → меню ⋮ → «Установить приложение» / «Добавить на главный экран».
- **iPhone (Safari):** откройте адрес → кнопка «Поделиться» → «На экран „Домой“».

## Простые дела и привычки

Раздел «Привычки» — два уровня дел:
- **Простые** (20 дел на 1–10 минут, +5 очков): вода, растяжка, проветрить, 5 медленных вдохов, одна страница книги… —
  для дней, когда нет настроения ни на что. Кнопка «Нет настроения ни на что» на экране «Сейчас» показывает три таких дела.
- **Посерьёзнее** (13 дел на 10–45 минут, +15, а от 30 минут +20): зарядка, тренировка, навести порядок в комнате,
  загрузить посудомойку, пропылесосить, приготовить еду, покрасить или собрать одну миниатюру…

Закрепление: булавка у любого дела → выбрать дни (каждый день, по будням, по выходным или свои дни).
Закреплённые привычки появляются на экране «Сейчас» в списке «Привычки на сегодня»; за выполнение всех — бонус +10.
У каждой привычки своя серия: пропуск в незапланированный день её не прерывает.

У каждого дела есть «Зачем», «Как закрепить» и якорь («после того как…»). Можно добавлять свои дела любого уровня.
Внизу раздела — 9 советов, как вырабатывать привычки. Любое выполненное дело сохраняет общую серию дней.

## Claude в приложении

Что умеет:
- **«Спросить Claude»** на экране «Сейчас»: опишите самочувствие своими словами, и Claude предложит 1–3 задачи, объяснит выбор и подскажет самое маленькое первое действие.
- **«Разбить на шаги»** в редакторе задачи: Claude предложит 3–7 конкретных шагов по 5–45 минут.
- **«Заполнить оценки с Claude»**: настроения, сложность, креативность, важность и срочность.
- **«Итоги недели от Claude»** на экране «Статистика».

Подключение:
1. Зарегистрируйтесь на [console.anthropic.com](https://console.anthropic.com) и пополните баланс. Это отдельная оплата по факту использования, подписка claude.ai здесь не действует.
2. **Settings → Limits**: поставьте месячный лимит расходов, например $5.
3. **API Keys → Create Key**, скопируйте ключ (`sk-ant-…`).
4. В приложении: **Настройки → Claude**, вставьте ключ, выберите модель и нажмите «Проверить ключ».

Ключ хранится только в браузере этого устройства и не попадает в синхронизацию через GitHub. Названия задач, шагов и заметки отправляются в Anthropic для обработки.
Модель по умолчанию — Opus 5.5 (~2–4 цента за запрос); Sonnet 5.5 вдвое дешевле, Haiku 5.5 почти бесплатна.

## Как устроена синхронизация

- Приложение работает без интернета: всё сохраняется в браузере.
- При открытии, через 4 секунды после изменений и по кнопке данные сливаются с файлом в GitHub.
- Слияние идёт по каждой записи: побеждает более свежая версия. Поэтому правки с двух устройств не затирают друг друга целиком.
- Удаление тоже синхронизируется: удалённая запись хранится с пометкой «удалено».
- Резервная копия: «Настройки → Скачать копию». К тому же GitHub хранит историю всех версий файла.

## Ограничения

- На телефоне браузер «усыпляет» свёрнутые приложения, поэтому уведомление о конце таймера может прийти с опозданием,
  пока вы не откроете приложение. Время при этом считается правильно.
- Вибрация в браузере на iPhone не поддерживается.

## Структура кода

- `src/types.ts` — модель данных
- `src/store.ts` — состояние и все действия (шаги, очки, таймер, награды)
- `src/lib/` — логика: прогресс, очки и серии (`game.ts`), достижения, подбор задач, синхронизация, звук
- `src/pages/` — экраны, `src/components/` — общие компоненты
